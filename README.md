## Основные возможности

- Управление более чем **15 бизнес-сущностями**
- Автоматическая генерация производственных задач
- Автоматизированный складской учет
- Управление технологическими процессами
- Иерархическое отображение данных с помощью TreeView
- JWT-аутентификация
- Поиск и пагинация
- Feature-Sliced Design


## Технологии

## Запуск системы

* git clone https://github.com/tr0stals/crm-practice.git

### Запуск Backend
* cd backend
* npm install
* npm run start

### Запуск Frontend
* cd frontend
* npm install
* npm run dev
